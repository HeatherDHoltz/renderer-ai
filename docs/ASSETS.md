# Asset provenance

- `gallery/baseline.png`: rendered from the initial copied renderer by this project; original scene layout and source were supplied by Heather. No external art or models.
- `gallery/shapes.png`: this renderer's analytic primitives, generated by `cargo run --release --locked --example shapes`; no external assets.
- `gallery/glass.png`: analytic geometry and materials generated by `cargo run --release --locked --example glass`; no external assets.
- `assets/uv-sphere.obj`: generated latitude/longitude sphere fixture, 12 segments and 6 latitude divisions; 62 shared positions and 120 triangles, per-corner UVs and unit vertex normals. No external model.
- `assets/uv-grid.png`: generated 64×32 color atlas with four colored quadrants and grid lines; no external art.
- `scenes/mesh.json` reuses the sphere geometry twice with flat/smooth normals; `gallery/mesh.png` was rendered with the documented CLI command and default 640×420 settings.
- `assets/benchmark-grid.obj` and `scenes/benchmark.json`: deterministic 64×64 sinusoidal grid, 4,225 vertices / 8,192 triangles, recreated by `python3 scripts/generate_benchmark.py`. `gallery/wave.png` is the inspected default BVH render.
- `gallery/aa-center.png` / `aa-128.png`: analytic/checker AA diagnostics at 480×270, center 1 spp versus seeded jittered 128 spp.
- `gallery/soft-1.png`, `soft-shadows.png`, and `soft-small.png`: inspected 320×224 rectangular-light diagnostics, generated from the included soft-shadow scenes; exact commands in SAMPLING.md.
- `assets/studio.hdr`: synthetic 256×128 linear Radiance RGBE map with three angular softboxes and a dim upper/lower field, generated entirely by `cargo run --release --locked --example generate_environment`. No photograph or external environment. Values exceed one before display mapping.
- `gallery/physical-studio.png`: inspected 960×540, 256-spp environment-only render of `scenes/physical_studio.json`; command, material ordering, and limitations in PHYSICAL.md. The accompanying raw HDR stays in ignored `output/`.
- `gallery/animation-{first,middle,last}.png`: actual 640×420, 32-spp frames 0/8/16 of the included kinetic sculpture, at 8 fps; analytic geometry and the existing generated OBJ only. Sequence command and composition in ANIMATION.md.
- `gallery/scatter.png` and `garden.png`: actual procedural renders from the checked generator configs; all geometry is analytic, no external assets. Full commands/settings in PROCEDURAL.md.
- `assets/torus.obj`: project-generated closed Y-axis torus (R=1, r=0.24), 2,304 positions / 4,608 triangles, vertex normals and independent seam UVs. Recreate with `python3 scripts/generate_torus.py` (Python standard library only).
- `scenes/ai_gallery.json`: Codex-authored still-life scene following the documented constrained prompt; project-generated meshes, analytic shapes, and synthetic environment only. No external art or model service.
- `gallery/hero.png`: inspected 1200×800, 512-spp render of that still life, using only the generated meshes and environment above. Exact command/settings are in GALLERY.md; raw HDR stays in ignored `output/`.
- `assets/gems/zsky-jewel-01.obj` through `04.obj`: **Jewel by Zsky**, downloaded from Poly Pizza under **CC BY 3.0**, converted/adapted for this renderer. The fourth uses a repaired outer hull. Required creator/source/license/change notices and SHA-256 metadata are in [assets/gems/ATTRIBUTION.md](../assets/gems/ATTRIBUTION.md). This third-party license remains applicable independently of the unassigned repository source-code license.
- Supplemental emerald step/cabochon geometry, procedural gold/blue/red stone textures, and the gem light-tent HDR are project-generated. Gallery panels and the light-sweep GIF use actual Rust-rendered images; Pillow adds labels/layout and GIF encoding only. [GEMS.md](GEMS.md) records settings, regeneration, attribution, and optical approximations.
- Course slides, handouts, syllabus, and class submission files are not redistributed here.

No license has been assigned to project-authored source files. Third-party gem meshes retain CC BY 3.0 and their attribution notices; rendered adaptations also credit Zsky. Dependency licenses remain those declared by their respective packages.

## Browser workshop

`workbench/assets/props/` contains five CC0 Poly Haven models: Wooden Table 03 (Gabriel Radić), Wooden Bookshelf Worn (Ulan Cabanilla), Wooden Candlestick (Josh Dean), Magnifying Glass 01 (Nazar Borodavka), and Wooden Hammer 01 (James Ray Cock). The adapted glTF files retain geometry and only the 1K diffuse maps; normal and ARM maps were removed. [Full source URLs, authors, and adaptations](../workbench/assets/props/CREDITS.md), [download/adaptation checksums](../workbench/assets/props/sources.json), and a reproducible importer accompany the models. They total roughly 9 MB including geometry and textures. This is a background budget, not a rendering benchmark.

The live browser room shell, window, plant, book spines, sketch, trays, eyepiece, and brilliant-cut mesh are project-generated. Cabochon/step-cut meshes and three reference render images are unchanged runtime copies from this repository, with SHA-256 records in `workbench/assets/references.json`. The reference panel retains the Zsky/CC BY 3.0 credit. Live geometry does not use the Zsky models.

`workbench/vendor/` contains the required Three.js 0.180.0 modules and MIT license, vendored from the official npm `three@0.180.0` package for offline runtime use. This third-party license does not assign a repository-wide license.
